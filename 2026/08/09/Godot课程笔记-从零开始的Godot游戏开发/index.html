Godot 课程笔记

一、导入素材模糊问题 —— 纹理过滤

导入图片素材后显示模糊，原因在于纹理过滤模式。Godot 提供两种过滤方式：

  • 邻近过滤（Nearest Filter / 最近邻）：这个位置该显示什么颜色，就直接拿离它最近的像素颜色来用。效果：边缘锐利、像素感强，放大后会出现明显的"马赛克"颗粒感。

  • 线性过滤（Linear Filter）：参考周围几个像素，把颜色做一个平滑的混合。效果：边缘平滑、模糊过渡，放大后没有锯齿感。

选择规则

  • 像素风格（像素画、复古风）：用邻近过滤，保持像素的锐利感。

  • 非像素风格（普通插画、写实贴图）：用线性过滤，画面更平滑。

设置位置：选中素材 → 导入面板（Import）→ Filter（过滤模式），可选 Nearest / Linear 等；也可以在项目设置里统一设置默认过滤模式。

二、节点命名规范

  • 节点命名采用大驼峰命名法（PascalCase）：每个单词首字母大写，单词间不加分隔符。

  • 例：Player、MainCamera、TileMapLayer。

  • 这样命名的好处：与引擎内置节点风格一致，脚本里引用时不易混淆，也方便区分小驼峰命名的函数/变量（player、mainCamera）。

三、TileMap / TileSet / TileSetLayer

  • TileMap：用来在二维网格上摆放瓦片、绘制地图的节点。

  • TileSet：它是 TileMap 要使用的瓦片的资源库。不只是存放瓦片，还可以给每种瓦片附加额外信息，比如：

    • 碰撞（physics）
    • 导航（navigation）
    • 遮挡（occlusion）

  • TileSetLayer：实际执行绘画操作的层（画布）。

类比记忆

  • TileMap = 颜料

  • TileSet = 调色板

  • TileSetLayer = 实际执行绘画操作的画布

工作流程

  1. 先创建 TileSet，导入瓦片资源（把瓦片图切分成格子）。

  2. 给 TileSet 的每个瓦片按需配置碰撞 / 导航 / 遮挡。

  3. TileMap（或其图层）选择瓦片进行绘制，把地图"画"出来。

四、常见的 2D 节点

  • Node2D：所有 2D 节点的基类。自身可设置位置（position）、旋转（rotation）、缩放（scale）。

  • CharacterBody2D：角色类物体（玩家、NPC）。通常配合 move_and_slide() 等移动方法，在 _physics_process() 里做移动与碰撞。

  • RigidBody2D：刚体。完全由物理引擎驱动（受重力、力、碰撞影响），适合做被推的箱子、弹跳物等。

  • 其他常用 2D 节点：

    • Sprite2D：显示一张 2D 图片。
    • AnimatedSprite2D：播放动画序列帧，逐帧。
    • Area2D：区域，检测其他物体进出、重叠（触发型，不物理阻挡）。
    • StaticBody2D：静态物体（地板、墙壁），不移动但可以挡住别人。
    • Camera2D：2D 摄像机，画面跟随它。
    • CanvasLayer：画布层，常用于 UI、血条等不受坐标影响的层。

五、游戏循环回调

  • _process(delta)：每帧都调用，执行频率跟帧率走（比如 60fps 每秒调 60 次）。适合做普通逻辑：输入响应、动画播放、即时更新。

  • _physics_process(delta)：每个物理帧固定频率调用，默认 60 次/秒，与渲染帧率无关。适合做物理相关的逻辑：移动角色、碰撞检测。

补充一点：物理帧频率恒定，游戏内计算更稳定；普通 _process 依赖帧率，掉帧时可能不稳定。

六、GDScript 语法两个要点

  • := ：类型推断赋值。写 var name := "player" 时，Godot 自动推断 name 的类型（这里是 String），比直接 = 多了类型检查。

  • &"xxx" ：StringName 字面量。&"hello" 生成 StringName（字符串名），常用于节点组、属性名、信号名等大量重复比较的场景，比普通字符串比较更快，内存也更省。

七、信号与 connect

  • 信号（signal）是 Godot 的消息机制：一个节点发出事件，其他节点监听并响应。

  • connect：把信号和接收方的方法连接起来。

    button.pressed.connect(_on_pressed)

    当 button 发出 pressed 信号时，自动调用 _on_pressed()。

  • 也在编辑器里用节点面板的"信号"标签页连接，连接后会自动生成并绑定处理函数。

  • 断开用 disconnect(...)。

八、什么是场景

  • 场景（Scene）是 Godot 的基本构建单元：一棵由节点组成的树（Node 树）。

  • 一个场景 = 一些节点的组合 + 它们的关系，表示游戏里的一个对象/关卡/元素（比如一个玩家、一个敌人、一个关卡）。

  • 场景可以嵌套：把一个场景作为节点放进另一个场景里（实例化），实现模块化复用。

  • 保存为 .tscn 文件，游戏程序就是由一个大场景把各个小场景组合起来的。

附：TileSet 物理层的操作步骤（碰撞配置）

  1. 选中 TileSet 资源，切到"物理层（Physics Layers）"标签页。

  2. 添加（Add）一个物理层（Physical Layer）。

  3. 在瓦片集编辑器里选择"点击绘制"工具（Paint）。

  4. 在瓦片集上框选要设置碰撞的瓦片，被选中的瓦片会变蓝色，表示这些瓦片带有碰撞信息。

  5. 之后在 TileMap 里绘制这些瓦片时，就会带碰撞体。
