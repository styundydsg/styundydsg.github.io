计算机图形学-四元数

2026/8/19 Unity

四元数把旋转压成四个数：本质上是转轴加转角，不会万向节死锁。三个自由度：偏航-Y轴，俯仰-X轴，-横滚-Z轴俯仰拉到90度，万向节死锁，丢死一个自由度

数学层面：绝对不可逆

如果"不可逆"指的是用欧拉角记录旋转过程，那答案就是：是的，数学上绝对不可逆，且信息永久丢失了。

这是核心所在。当发生万向节死锁时，两个旋转轴重合，意味着无数种不同的旋转路径，最终指向了同一个姿态。

举个例子：

路径A：先绕X轴转30°，再绕Y轴转90°，最后绕Z轴转40°。

路径B：先绕X轴转0°，再绕Y轴转90°，最后绕Z轴转70°。

在死锁（Y轴=90°）的那个瞬间，路径A和路径B最终指向的朝向是完全一样的。从数学上，系统只记录下了最终的三个角度（30°，90°，40°），但它已经无法反推出你当初到底是按路径A转过来的，还是按路径B，或是其他无数种路径转过来的。

这就是"不可逆"的真正含义：你无法从最终的两个有效角度（因为第三个自由度已经合并了），还原出第三个自由度的原始独立运动数据。这个"历史信息"在数学计算中被永久性地丢弃了。

四元数看成一个旋转轴+旋转角度写成q=(w,x,y,z),x y z是轴，w是角度

四元数旋转应用示例：绕 Y 轴旋转 90°

在计算机图形学中，四元数常用于表示三维空间中的旋转，以避免欧拉角的"万向节死锁"问题，并提高插值平滑度。

🎯 示例：绕 Y 轴旋转 90°（π/2 弧度）

1. 定义旋转参数

  • 旋转轴：Y 轴，单位向量为 \(\vec{u} = (0, 1, 0)\)

  • 旋转角度：\(\theta = 90^\circ = \frac{\pi}{2}\) 弧度

2. 构造单位四元数

根据公式：

\[ q = \cos\left(\frac{\theta}{2}\right) + \sin\left(\frac{\theta}{2}\right)(u_x i + u_y j + u_z k) \]

代入数值：

  • \(\frac{\theta}{2} = \frac{\pi}{4}\)
  • \(\cos\left(\frac{\pi}{4}\right) = \sin\left(\frac{\pi}{4}\right) = \frac{\sqrt{2}}{2}\)
  • \(u_x = 0,\ u_y = 1,\ u_z = 0\)

得到：

\[ q = \frac{\sqrt{2}}{2} + \frac{\sqrt{2}}{2}j \]

即四元数为：

\[ q = \left( \frac{\sqrt{2}}{2},\ 0,\ \frac{\sqrt{2}}{2},\ 0 \right) \]

3. 应用旋转

若有一个向量 \(\vec{v} = (1, 0, 0)\)（X 轴方向），将其嵌入为纯虚四元数 \(v = 0 + 1i + 0j + 0k\)，则旋转后的向量为：

\[ v' = q v q^* \]

其中 \(q^*\) 是 \(q\) 的共轭，即 \(q^* = \frac{\sqrt{2}}{2} - \frac{\sqrt{2}}{2}j\)。

计算后可得：

\[ v' = 0 + 0i + 0j + 1k \Rightarrow \vec{v'} = (0, 0, 1) \]

说明：原 X 轴方向的向量绕 Y 轴旋转 90° 后变成了 Z 轴方向，符合预期。
