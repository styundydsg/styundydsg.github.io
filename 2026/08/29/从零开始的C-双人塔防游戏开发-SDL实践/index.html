从零开始的C++双人塔防游戏开发-SDL实践

2026/8/29 从零开始的C++双人塔防游戏开发 SDL

Surface 与 Texture 的区别

SDL_Surface* sur_img = IMG_Load(...);
SDL_Texture* tex_img = SDL_CreateTextureFromSurface(renderer, sur_img);
  • Surface：存在内存（CPU 侧）的像素数据，可以读写像素，但不能直接渲染。
  • Texture：存在显存/GPU（驱动侧）的纹理，只能渲染不能读写（一般如此）。
  • 两者的桥梁就是 SDL_CreateTextureFromSurface。文件 → Surface → Texture 是 SDL 加载图片的标准流程。
  • 文字也一样：TTF_RenderText_Blended 产出 Surface，再转成 Texture。

渲染管线

SDL_SetRenderDrawColor(renderer, 0, 0, 0, 255);  // 画笔颜色
SDL_RenderClear(renderer);                        // ① 清屏为纯黑
SDL_RenderTexture(renderer, tex_img, nullptr, &rect_img);  // ② 画图
filledCircleRGBA(...);                            // ③ 画半透明圆
SDL_RenderTexture(renderer, tex_text, nullptr, &rect_text); // ④ 画文字
SDL_RenderPresent(renderer);                      // ⑤ 交换缓冲，真正显示
  • 双缓冲：所有绘制画在后台缓冲，SDL_RenderPresent 才一次性呈现，避免闪烁。
  • 绘制顺序就是图层顺序：后画的盖住先画的 → 最终视觉效果是"圆压在图片上、文字压在圆上"。
  • SDL_RenderTexture 的第 3、4 参数：源矩形 nullptr=整张图，目标矩形 &rect_img=画到哪、多大。这里图片和文字用了同一个目标位置（鼠标坐标），所以文字会叠在图片上。
  • SDL_FRect 的 w/h 直接取自 sur_img->w/h，即原图尺寸。

SDL3_mixer 3.0 —— 全新对象模型

完整链条：MIX_Mixer (混音设备) → MIX_Audio (音频数据) → MIX_Track (播放轨道)

MIX_CreateMixerDevice(SDL_AUDIO_DEVICE_DEFAULT_PLAYBACK, &spec); // 1. 建混音器（绑定音频设备）
MIX_LoadAudio(mixer, u8"./assets/music.mp3", true);              // 2. 加载音频（true=允许循环）
MIX_CreateTrack(mixer);                                          // 3. 建轨道
MIX_SetTrackAudio(track, music);                                 // 4. 把音频挂到轨道上
MIX_PlayTrack(track, props);                                     // 5. 用属性参数播放
  • MIX_Init() 在 SDL3_mixer 中不再需要参数（SDL2 要传 MIX_INIT_MP3 等 flags）。
  • MIX_LoadAudio 第三个参数是 predecode：true 表示解码后常驻内存（适合循环播放的音乐/音效），false 流式解码（省内存）。
  • MIX_PROP_PLAY_LOOPS_NUMBER = -1 表示无限循环，这是 mixer 3.0 的约定。
